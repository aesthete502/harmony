# Harmony 课程内容大纲

> 版本 v0.1 · 状态：待确认
> 配套技术方案见对话记录；本文档只描述「学什么、怎么练、怎么判定学会」。

---

## 0. 设计原则

1. **先构成，后听觉。** 每一关都先能「在键盘上指出这个和弦由哪几个音组成」，再练「听出来」。
2. **听觉训练必须有参照。** 除绝对音高模块外，所有听辨题都会先给出主音或调性中心，考的是相对关系。
3. **一次只增加一个变量。** 新关卡在同一题型上只加一个新维度（比如 L6 只在 L4 的三和弦基础上加「七音」），避免同时引入多个新概念。
4. **错题驱动复习。** 每组题里固定掺入历史错题和已通关内容的随机抽题，靠重复而不是靠刷量。
5. **内容全量、按关解锁。** 数据层一次性建好所有音阶/和弦/音程，界面按关卡逐步开放，避免初学者被 30 种音阶淹没。

## 1. 全局约定

### 1.1 记谱与命名

| 项 | 规则 |
|---|---|
| 音名 | `C D E F G A B`，升降号显示为 `♯ ♭` |
| 拼写 | 跟随调性拼写，不用统一升号。F 大调写 `B♭` 而不是 `A♯`；D 小调写 `B♭` |
| 八度 | 科学音高记法，中央 C = `C4` = MIDI 60 |
| 音区范围 | 练习默认 `C3–B5`；探索页可扩展到 `A0–C8` |
| 唱名 | 两种模式：**音级数字**（1–7，默认）与**首调唱名**（do–re–mi） |
| 和弦记号 | 流行/爵士记法：`C` `Cm` `Cdim` `Caug` `Cmaj7` `C7` `Cm7` `Cm7♭5` `Cdim7` |
| 罗马数字 | 大调 `I ii iii IV V vi vii°`；小调用和声小调习惯，`V` 为大三和弦 |
| 中文术语 | 主音 tonic / 上主音 supertonic / 中音 mediant / 下属音 subdominant / 属音 dominant / 下中音 submediant / 导音 leading tone |

### 1.2 每关统一结构

每关都包含以下六块，缺一不算完成：

1. **目标**：一句可检验的话。
2. **概念清单**：本关新引入的术语，不超过 8 个。
3. **探索预设**：探索页里一键载入的示例，用于「看构成」。
4. **构成题**：在键盘上点音 / 选音，考「由什么组成」。
5. **听辨题**：播放音频，考「听出来是什么」。
6. **讲义**：200–400 字中文，含 1 张图（键盘或谱面截图式 SVG）和 1 个听觉例子。

### 1.3 出题与通关规则

| 项 | 规则 |
|---|---|
| 每组题量 | 默认 10 题，可在设置里改 20 |
| 出题配比 | 70% 当前关 · 20% 历史错题 · 10% 已通关关卡的随机抽题 |
| 通关条件 | 该关累计作答 ≥ 规定题量，且正确率 ≥ 85% |
| 错题 | 答错即进错题本；同一题连续答对 2 次后移出 |
| 参照音 | 相对听辨默认先播主音（可关闭，关闭后正确率单独统计） |
| 计时 | 默认不限时；可在设置里开「每题 8 秒」挑战模式，只影响额外统计 |
| 会话中断 | 随时退出，本次会话进度保留，下次继续 |

### 1.4 可调难度参数

这些参数在设置页暴露，直接影响出题：

- 根音范围：默认 12 个半音全用；可锁到「只练白键根音」
- 播放方式：上行 / 下行 / 和声（同时）
- 选项数：4 选 1（默认）/ 6 选 1 / 8 选 1
- 是否给参照音
- 音色：合成音色（默认）/ 钢琴采样（后续）

## 2. 分级内容

### L1 音名、半音、五线谱位置

**目标**：看到任意一个音名或谱面位置，能立刻在键盘上找到它；反之亦然。

**概念清单**：音名、八度、半音与全音、升号/降号、等音（`C♯ = D♭`）、中央 C、高音谱号、五线四间与加线。

**探索预设**
- C4 单音（键盘 + 谱面同步高亮）
- C 大调音阶（先只看位置，不讲公式）
- 一组等音：`C♯4` / `D♭4`

**构成题**
- 给出音名（如 `F♯4`），在键盘上点出该键
- 给出键盘上高亮的键，写出音名（文本输入或四选一）
- 给出谱面上的一个音符，在键盘上点出对应键

**听辨题**
- 只做「两个音谁更高 / 是否同音」，不做音名判断
- 目的：建立「声音有高低、有距离」的直觉，不涉及本关的知识点考核

**讲义要点**：为什么一个八度是 12 个半音；钢琴黑键「2 + 3」分组如何帮你定位；`E–F`、`B–C` 之间为什么没有黑键；等音是同一个键的两个名字。

**通关**：20 题 · 90%

**易混点**：把 `C4` 认成 `C5`；`E–F`/`B–C` 的半音关系；升降号的方向（`♯` 往右）。

---

### L2 大调音阶与音级

**目标**：给出任意根音，能构出大调音阶，并能说出每个音是第几级。

**概念清单**：音阶、主音、音级（1–7）、全音/半音结构「全全半全全全半」、导音、调号（先只出现 C / G / F 三个调）。

**探索预设**
- C 大调（显示公式条：`1 2 3 4 5 6 7` + `全全半全全全半`）
- G 大调（对比：只把 F 变成 F♯）
- F 大调（对比：只把 B 变成 B♭）

**构成题**
- 给出「D 大调」，在键盘上点出全部 7 个音
- 给出一个音阶，问第 5 级是哪个音
- 判断某个音是否属于该音阶（如 `F♮` 属于 G 大调吗）
- 找出这个音阶的导音

**听辨题**
- 播放上行/下行大调音阶，判断「最后一个音是不是主音」
- 给出主音，听第 3 级，判断「明亮 / 暗淡」两选一（为 L3 的三度埋伏笔）

**讲义要点**：大调公式的由来（相邻音的半音数）；导音为什么「想往上解决」；调号只是把同一个公式搬到不同起点。

**通关**：15 题 · 85%

**易混点**：根音不是 C 时忘记升降；把「第 5 级」和「第五个白键」搞混。

---

### L3 音程：大小三六、纯四五八

**目标**：能算出并听出这 6 种最常用音程：大二度以外的重点是小三、大三、纯四、纯五、大六、小六、纯八。

**概念清单**：度数（数音名个数）、性质（大/小/纯）、半音数、协和与不协和、音程转位（大↔小、纯↔纯）。

**半音数对照（本关范围）**

| 音程 | 半音 | 音程 | 半音 |
|---|---|---|---|
| 纯一度 | 0 | 纯五度 | 7 |
| 小三度 | 3 | 小六度 | 8 |
| 大三度 | 4 | 大六度 | 9 |
| 纯四度 | 5 | 纯八度 | 12 |

**探索预设**
- `C4–E4` 大三度 / `C4–E♭4` 小三度（A/B 对比）
- `C4–G4` 纯五度
- `C4–A4` 大六度 / `C4–A♭4` 小六度

**构成题**
- 给出根音 + 音程名（如「从 `E♭4` 往上构大六度」），在键盘上点目标音
- 给出两个音，判断音程
- 给出音程，问它的转位是什么

**听辨题**
- 三种播放方式：上行、下行、和声
- 6 选 1；答后显示谱面并复听

**讲义要点**：半音数才是本质，度数是数音名的「格子」；三度决定明暗、五度决定稳定；大六度和小七度容易混，靠「有没有跨过八度的一半」来分辨。

**通关**：25 题 · 85%

**易混点**：大六度 vs 小七度（8 vs 10 半音，实际差 2）；纯四 vs 增四；`E–F` 是二度不是一度。

---

### L4 三和弦与转位

**目标**：构出并听出大三、小三、减三、增三四种三和弦，认识原位与两个转位。

**概念清单**：三度叠置、根音/三音/五音、和弦性质、低音与根音的区别、转位（原位 / 第一转位 / 第二转位）。

**和弦结构**

| 和弦 | 记号 | 半音结构 | 例（C 为根音） |
|---|---|---|---|
| 大三 | `C` | 0–4–7 | C E G |
| 小三 | `Cm` | 0–3–7 | C E♭ G |
| 减三 | `Cdim` | 0–3–6 | C E♭ G♭ |
| 增三 | `Caug` | 0–4–8 | C E G♯ |

**探索预设**
- `C` / `Cm` / `Cdim` / `Caug` 四个并排 A/B 试听
- `C` 的原位、第一转位（`E G C`）、第二转位（`G C E`）

**构成题**
- 给出和弦名（如 `F♯m`），在键盘上点出三个音
- 给出三个音，判断性质与根音
- 给出和弦，问第一转位的低音是哪个音
- 判断某和弦是原位还是转位

**听辨题**
- 性质 4 选 1（先只考原位）
- 通关后解锁：性质 + 转位（4 性质 × 3 转位 = 12 选项过多，改为两段式：先判性质，再判转位）

**讲义要点**：三度叠置是和弦的定义方式；减三和弦的「悬空感」来自两个小三度；转位只换低音，不换根音——这是最容易搞错的地方。

**通关**：30 题 · 85%

**易混点**：减三 vs 小三（只差五音一个半音）；转位后把低音当成根音。

---

### L5 全部音程 + 自然小调

**目标**：补齐二度、七度与增减音程；掌握自然小调，理解关系大小调。

**概念清单**：大二/小二、大七/小七、增四/减五（三全音）、自然小调「全半全全半全全」、关系大小调、平行大小调。

**新增音程**

| 音程 | 半音 | 音程 | 半音 |
|---|---|---|---|
| 小二度 | 1 | 小七度 | 10 |
| 大二度 | 2 | 大七度 | 11 |
| 增四 / 减五 | 6 | — | — |

**探索预设**
- `C4–B4` 大七 vs `C4–B♭4` 小七
- `C4–D♭4` 小二 vs `C4–D4` 大二
- A 自然小调 ↔ C 大调（同一批音，不同主音）

**构成题**
- 全 12 种音程的识别与构写
- 构出指定根音的自然小调
- 给出一个大调，找它的关系小调；给出小调，找平行大调
- 判断某音属于大调还是关系小调

**听辨题**
- 12 种音程混合 4 选 1（选项按半音距离邻近抽取，避免太容易）
- 大调 vs 自然小调（先同主音对比，再关系调对比）

**讲义要点**：关系大小调共享调号、共享音，区别只在「以谁为中心」；小调的暗淡来自小三度与降六度；三全音是最不稳定的音程，后面属七和弦会再见到它。

**通关**：30 题 · 85%

**易混点**：关系小调 vs 平行小调（前者同音不同主音，后者同主音不同音）；增四与减五听感相同、写法不同。

---

### L6 七和弦与转位

**目标**：构出并听出五种七和弦，理解七音带来的张力差异。

**概念清单**：七音、大七/小七/属七/半减七/减七、转位（三种）、属七的解决倾向。

**和弦结构**

| 和弦 | 记号 | 半音结构 | 例 |
|---|---|---|---|
| 大七 | `Cmaj7` | 0–4–7–11 | C E G B |
| 属七 | `C7` | 0–4–7–10 | C E G B♭ |
| 小七 | `Cm7` | 0–3–7–10 | C E♭ G B♭ |
| 半减七 | `Cm7♭5` | 0–3–6–10 | C E♭ G♭ B♭ |
| 减七 | `Cdim7` | 0–3–6–9 | C E♭ G♭ B♭♭ |

**探索预设**
- `Cmaj7` vs `C7`（只差七音半音，重点对比）
- `Cm7` vs `Cm7♭5`（只差五音）
- `C7` → `F`（听属七如何解决）

**构成题**
- 构出指定七和弦
- 判断四个音构成的和弦性质
- 求转位、判断转位
- 从三和弦升级：把 `C` 变成 `Cmaj7` 需要加哪个音

**听辨题**
- 五种性质 5 选 1
- 重点对比题：`maj7` vs `7`、`m7` vs `m7♭5`
- 通关后解锁转位判断（同 L4 的两段式）

**讲义要点**：七音是「加在稳定结构上的不协和」，所以七和弦天然有进行的方向；属七唯一含有三全音，解决欲望最强；减七由三个小三度叠成，对称、无明确调性。

**通关**：35 题 · 85%

**易混点**：大七 vs 属七（11 vs 10 半音）；半减七 vs 小七（只差五音）；减七的七音是重降。

---

### L7 音阶家族：五声、和声小调

**目标**：在同一根音下比较不同音阶，能用「特征音」而不是背公式来区分。

**概念清单**：和声小调、旋律小调（上行）、大调五声、小调五声、布鲁斯音阶（选学）、特征音。

**音阶结构**

| 音阶 | 半音结构 | 特征 |
|---|---|---|
| 和声小调 | 0–2–3–5–7–8–11 | 升七级，产生增二度 |
| 旋律小调（上行） | 0–2–3–5–7–9–11 | 升六、七级 |
| 大调五声 | 0–2–4–7–9 | 无半音、无三全音 |
| 小调五声 | 0–3–5–7–10 | 无半音 |
| 布鲁斯 | 0–3–5–6–7–10 | 加降五级 |

**探索预设**
- C 大调 / C 自然小调 / C 和声小调 三连对比（只差 6、7 级）
- C 大调五声 vs C 大调（去掉 4、7 级）

**构成题**
- 构出指定音阶
- 给出音阶，找出与自然小调不同的那一个音
- 判断某音是否属于该音阶

**听辨题**
- 大调 / 自然小调 / 和声小调 / 大调五声 / 小调五声，5 选 1
- 重点对比：自然小调 vs 和声小调（听第 7 级是否升高）

**讲义要点**：和声小调的「异域感」来自增二度；五声音阶之所以「怎么弹都不难听」，是因为没有半音和三全音；特征音是记忆音阶的唯一高效方式。

**通关**：30 题 · 85%

**易混点**：和声小调 vs 旋律小调；小调五声 vs 大调五声（同一批音的两种中心）。

---

### L8 调式（教会调式）

**目标**：掌握七种调式，理解「同一批音、不同中心」以及每种调式的特征音。

**概念清单**：Ionian、Dorian、Phrygian、Lydian、Mixolydian、Aeolian、Locrian、特征音、调式主音。

**调式与特征音**

| 调式 | 相对大调的改变 | 特征音 |
|---|---|---|
| Ionian | 无（= 大调） | — |
| Dorian | ♭3 ♭7 | 大六度（比自然小调高） |
| Phrygian | ♭2 ♭3 ♭6 ♭7 | 小二度 |
| Lydian | ♯4 | 增四度 |
| Mixolydian | ♭7 | 小七度 |
| Aeolian | ♭3 ♭6 ♭7（= 自然小调） | — |
| Locrian | ♭2 ♭3 ♭5 ♭6 ♭7 | 减五度 |

**探索预设**
- C Ionian ↔ D Dorian ↔ E Phrygian（同一批白键，换中心）
- C Lydian（只把 F 变 F♯）vs C 大调
- C Mixolydian（只把 B 变 B♭）vs C 大调

**构成题**
- 构出指定调式
- 给出调式，指出它的特征音
- 给出音阶，判断是哪种调式
- 找出同一批音的其他调式主音

**听辨题**
- 第一段：Ionian / Dorian / Mixolydian / Aeolian 4 选 1（固定主音）
- 第二段：加入 Lydian / Phrygian
- 第三段：7 选 1（Locrian 最后）

**讲义要点**：不要背七套公式，记「改哪一个音」；Dorian 的大六度让它既暗又亮，是最好认的调式之一；Locrian 的减五度使它极少作为稳定调性使用。

**通关**：35 题 · 85%

**易混点**：Dorian vs Aeolian（差大六度）；Mixolydian vs Ionian（差小七度）；调式主音不是音阶的第一个白键。

### L9 和声功能与常见进行

**目标**：听出一段 4 个和弦的进行属于哪种常见模式，理解功能圈为什么这样走。

**概念清单**：罗马数字级数、功能（主 T / 下属 S / 属 D）、正格终止、变格终止、半终止、假终止、副属和弦（选学）。

**功能分组**

| 功能 | 级数（大调） |
|---|---|
| 主 T | I、vi、iii |
| 下属 S | IV、ii |
| 属 D | V、vii° |

**要练的进行**

| 名称 | 级数 | 说明 |
|---|---|---|
| 正格进行 | I–IV–V–I | 最基础 |
| 二五一一 | ii–V–I | 爵士/流行通用 |
| 流行四和弦 | I–V–vi–IV | 大量流行歌 |
| 小调变体 | vi–IV–I–V | 同上，从 vi 起 |
| 50 年代 | I–vi–IV–V | 老歌标配 |
| 假终止 | V–vi | 该回 I 却去了 vi |

**探索预设**
- C 大调 `I–IV–V–I`，逐个和弦高亮 + 显示低音线
- `V–vi` 假终止对比 `V–I`

**构成题**
- 给出调性与级数，写出对应和弦
- 给出和弦串，标出功能（T/S/D）
- 判断终止式类型

**听辨题**
- 播放 4 个和弦（每和弦 1 拍），4 选 1 判断进行
- 只听低音线，判断级数走向
- 判断最后一个和弦是否「回来了」

**讲义要点**：功能圈 `T → S → D → T` 是张力的循环；V 想回 I 是因为导音与三全音的解决倾向；小调里的 V 通常用和声小调的大三和弦，这是小调最反直觉的一点。

**通关**：30 题 · 85%

**易混点**：小调级数用自然小调还是和声小调（本课程统一用和声小调的 V）；`I–V–vi–IV` 与 `vi–IV–I–V` 听感几乎相同，靠起始和弦区分。

## 3. 附加模块 A：绝对音高

与主线完全分离，独立入口、独立统计、不参与关卡解锁。

**定位**：可选实验性模块。明确告知用户这是长期训练，进度曲线波动大，且**不作为主进度的一部分**。

**训练方法**
- 每日上限 5–10 分钟，超出提示休息（防止疲劳导致误判）
- 固定使用同一种音色（合成音色），不随设置切换
- 有「参考音锚定」：先播 A4 或 C4 作为锚点，再听目标音
- 三阶段：白键 → 加黑键 → 和弦根音

**题型**
- 单音：听一个音，在键盘上点出音名（不用选项，直接点键）
- 选项模式：4 选 1（给相近音高做干扰项）
- 和弦根音：听一个和弦，判断根音音名

**统计**
- 独立曲线，按音名分类的正确率热力图（12 个键哪个最弱）
- 不显示连击和排名，只显示趋势
